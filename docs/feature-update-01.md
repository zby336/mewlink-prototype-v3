## 两项修改

1. Cat Profile 的基本信息和 Latest observation 之间新增 62px 左右的照护者组件。34px 圆形首字母头像部分重叠，最多五个可公开头像，余者 +N；显示去重照护人数并标注 Demo data。
2. Fed Tiger 表单改为视口内的独立覆盖层，固定头部及提交区，中间内容可滚动，底部包含 safe-area-inset-bottom。打开时隐藏底层主导航，保留照片、时间及区域说明、Cancel 和提交逻辑。

Figma 已复用原有字体、颜色、猫照片和详情内容，加入四档头像组件、隐私详情布局及 360×640 / 375×667 的喂食弹窗状态。原有四个 Tiger 详情状态均已加入同一头像组件，所有设计仍为可编辑图层。

## 照护统计和隐私

以新加坡日历日期计算距最后一次有效照护的天数，0–7 / 8–14 / 15–21 / 22–30 天分别使用 98% / 76% / 54% / 32% 透明度，超过 30 天移除。未来时间、无效记录、Seen、单纯观察和帮忙意愿均排除。同一人只按最后一次有效照护统计。

排序使用每个浏览器持久化的随机种子，不随 render 或照护频次排名。重新打开、切回页面、新加坡日期变化或记录更新时重新计算。

单独隐藏、全部隐藏和本人身份隐私选项均保存在本地；不删除照护记录、不改变人数。私密身份不进入展开列表的昵称和头像数据。原型没有账号后端，因此不能保证跨用户隐私；界面已经明确说明这一点。

默认示例人数：Tiger 6、Kopi 4、Oyen 3、Milo 3、Ash 2、Bubu 1。Tiger 中两位照护者匿名计数。

## 真实数据与 Demo 边界

当前没有真实照护数据库或账号系统。统计用固定时间戳的 Demo 照护记录，以及用户在当前浏览器完成的原型喂食操作记录。算法、记录去重和本地保存是真实实现；这些记录不是对现实照护行为的认证。

照片捕获继续使用原型演示图片，没有接入真实相机验证。观察记录和已有 Ask Mew 等流程继续保留原有 Mock 行为。网页及本地偏好不是跨设备同步系统。

响应式测试基于浏览器视口；没有进行实体 iPhone 测试。
